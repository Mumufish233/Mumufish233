## 我的规矩

1. **先预演，再动手** —— 不给看结果的改动不做
2. **可撤销** —— 每次操作都留撤销日志
3. **不删文件** —— 只移动，撞名加后缀
4. **不吹牛** —— 作品集上写的每项能力，背后都有一个跑通过的工具
5. **不刷量** —— 不买播放、不求三连
